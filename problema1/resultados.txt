1. EJEMPLO DONDE ALGORITMO ORIGINAL ES MALO

A = [1, 1, 1, 1, 1, 1, 1, 1, 1, 9]

Algoritmo original:
  Subconjunto: [1, 1, 1, 1, 1, 1, 1, 1, 1]
  Suma: 9

Solución óptima:
  Subconjunto: [1, 9]
  Suma: 10

Comparación:
  Suma original: 9
  Mitad del óptimo: 5.0
  ¿Original < Mitad del óptimo? False

SUPUESTOS Y CONDICIONES:
- Todos los elementos de A son enteros positivos
- B es un entero positivo
- El conjunto A puede tener elementos repetidos
- Buscamos maximizar la suma sin exceder B

ALGORITMO DE APROXIMACIÓN:
1. Ordenar A en orden descendente
2. Aplicar greedy: tomar elementos mientras quepan
3. Considerar tomar solo el elemento más grande no incluido
4. Retornar el mejor de los dos subconjuntos

GARANTÍA DE APROXIMACIÓN:
- Sea OPT la suma de la solución óptima
- Sea S1 el resultado del greedy en elementos ordenados
- Sea S2 = {elemento más grande que cabe solo}
- Nuestro algoritmo retorna max(suma(S1), suma(S2))

DEMOSTRACIÓN:
- Si existe un elemento x > B/2, entonces S2 = {x} da al menos B/2 ≥ OPT/2
- Si todos los elementos ≤ B/2, entonces el greedy es óptimo o muy cercano
- En el peor caso, el greedy deja de incluir elementos porque no cabe uno
- Ese elemento que no cabe es ≤ la suma actual del greedy
- Por tanto, greedy obtiene al menos OPT/2

COMPLEJIDAD:
- Ordenamiento: O(n log n)
- Greedy: O(n)
- Total: O(n log n)

def fuerza_bruta_optimo(A, B):
    from itertools import combinations
    inicio = time.time()
    mejor_suma = 0
    mejor_subconjunto = []
    
    for r in range(len(A) + 1):
        for subconjunto in combinations(A, r):
            suma = sum(subconjunto)
            if suma <= B and suma > mejor_suma:
                mejor_suma = suma
                mejor_subconjunto = list(subconjunto)
    
    fin = time.time()
    tiempo_ms = (fin - inicio) * 1000
    print(f"Tiempo fuerza_bruta_optimo: {tiempo_ms:.8f} ms")
    return mejor_subconjunto
